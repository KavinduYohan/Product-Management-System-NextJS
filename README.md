# ProductHub - Modern Product Management System

A beautiful, responsive product management system built with Next.js 15, TypeScript, and Tailwind CSS. Features a modern UI with glassmorphism effects, smooth animations, and comprehensive CRUD operations.

## ✨ New Features Added

### 🎨 Modern UI/UX
- **Glassmorphism Design**: Beautiful backdrop blur effects and modern aesthetic
- **Dark Gradient Themes**: Eye-catching gradient backgrounds and effects
- **Smooth Animations**: Custom CSS animations and transitions
- **Responsive Design**: Fully responsive across all devices (mobile, tablet, desktop)
- **Modern Typography**: Clean, readable fonts with proper hierarchy

### 🔐 Enhanced Authentication
- **Password Strength Indicator**: Real-time password strength validation
- **Form Validation**: Enhanced form validation with visual feedback
- **Loading States**: Visual feedback during authentication processes
- **Modern UI**: Glassmorphism effects and gradient designs

### 📊 Modern Dashboard
- **Sidebar Navigation**: Collapsible sidebar with modern design
- **Table & Grid Views**: Switch between table and grid layouts
- **Advanced Search**: Real-time product search functionality
- **Responsive Modals**: Beautiful modal dialogs with backdrop blur
- **Stock Status Indicators**: Visual indicators for inventory levels

### 🎯 Enhanced Product Catalog
- **Advanced Filtering**: Filter products by stock status
- **Multiple Sort Options**: Sort by name, quantity, etc.
- **View Modes**: Grid and list view options
- **Stock Analytics**: Summary statistics and insights
- **Modern Card Design**: Beautiful product cards with hover effects

## 🚀 Tech Stack

- **Frontend**: Next.js 15, React 19, TypeScript
- **Styling**: Tailwind CSS 4 with custom animations
- **Icons**: Heroicons
- **Database**: SQLite with better-sqlite3
- **Authentication**: JWT (JSON Web Tokens)
- **File Upload**: Multer for image handling
- **Notifications**: React Toastify

## Getting Started
First, run the development server:

```bash
npm i
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
## Available API endpoints 

* POST /api/products - Create a new product
* GET /api/products - Get a list of all products
* PUT /api/products/:id - Update a product
* DELETE /api/products/:id - Delete a product
* POST /api/auth/register -Register a user
* POST /api/auth/login -Login a user
* GET  /api/products/search?q=term -Search products
